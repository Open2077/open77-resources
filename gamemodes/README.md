# gamemodes

Complete game modes and their HUDs: free roam, races, pursuit, deathmatch, battle royale and example arenas. Pick one as your server's template, or read them to build your own.

| Resource | What it does | Docs |
|---|---|---|
| [`freeroam`](freeroam/) | Freeroam turns your server into an open Night City sandbox: players spawn, call cars, pick weapons, travel across the city and fight, and they can join races, foot races and PvP matches without changing servers. | [Writing a gamemode](https://open2077.net/docs/writing-a-gamemode) |
| [`open77_cordon`](open77_cordon/) | Cordon gives your server a battle royale for up to 64 players: everyone stages in a lobby, deploys onto the map, loots weapons, armor and healing from the ground, and fights while NCPD closes the city block by block until one player or squad is left. | [Cordon — battle royale](https://open2077.net/docs/cordon) |
| [`open77_cordon_hud`](open77_cordon_hud/) | Draws the Cordon battle royale interface for each player: crosshair and hitmarker, health, armor and ammo, the staging and deploy panels, kill feed, squad panel, result card, the tactical map and the cordon edge. | [Cordon — battle royale](https://open2077.net/docs/cordon) |
| [`open77_cordonlab`](open77_cordonlab/) | A test arena for the building blocks of the Cordon battle royale: each server command runs one experiment, such as a high drop, ghost spectating, cordon damage, the loot loop, revive at the body, a line of edge lights, vehicles, a server-flown AV or teams, and prints what it asked for and what came back. | [Cordon — battle royale](https://open2077.net/docs/cordon) |
| [`open77_cyberarena_example`](open77_cyberarena_example/) | An optional Gorilla Arms practice arena: players who walk to a configured site get temporary cyberware arms and PvP that applies only inside the arena's own routing bucket, then leave with their own implants untouched. | [Gorilla Arms](https://open2077.net/docs/gorilla-arms) |
| [`open77_cyberware_lab`](open77_cyberware_lab/) | A test arena for cyberware: a `/cyberlab` panel and command set that installs and removes Gorilla Arms and double-jump legs, grants Dash, Ground Slam and Reflex Overdrive, and probes effects, stamina, life state and routing. | [Cyberware](https://open2077.net/docs/cyberware) |
| [`open77_deathmatch`](open77_deathmatch/) | Kabuki Arena gives your server player-versus-player combat in Kabuki Market: a drop-in free-for-all you walk into from a station in the world, plus queued 1v1, 2v2 and 3v3 arena rounds on the same map. | [Deathmatch — running the Kabuki Arena PvP mode](https://open2077.net/docs/deathmatch) |
| [`open77_deathmatch_hud`](open77_deathmatch_hud/) | The combat HUD for [`open77_deathmatch`](../open77_deathmatch/): it shows players the fight (hitmarker, directional damage, health, armor, ammo, crosshair and streak callouts) alongside the match timer, kill feed, standings, enrolment panel and result banner. | [Deathmatch — running the Kabuki Arena PvP mode](https://open2077.net/docs/deathmatch) |
| [`open77_freeroam`](open77_freeroam/) | Saves players to your own MySQL database and adds `kick`, `ban` and `makeadmin` commands for the Freeroam template. | [Configure a SQL database](https://open2077.net/docs/database) |
| [`open77_hacking_lab`](open77_hacking_lab/) | A test arena for hacking: ACL-restricted `/hacklab` commands install hacking decks, Self-ICE and purge implants on chosen players, open scoped PvP between them, place them and apply statuses, so you can try every hack kind and its counterplay. | [Hacking and counterplay](https://open2077.net/docs/hacking) |
| [`open77_parkour_example`](open77_parkour_example/) | A free self-service Dash example: players type `/parkour install` to give themselves native ground Dash, Air Dash or both, with a Basic or Advanced preset. | [Native Dash and Air Dash](https://open2077.net/docs/dash) |
| [`open77_pvplab`](open77_pvplab/) | A test arena for the pieces a PvP arena is built from: server commands raise rings of props as walls, spawn NPC bots, assign teams and apply scripted damage, then print what they asked for and what came back. | [Deathmatch — running the Kabuki Arena PvP mode](https://open2077.net/docs/deathmatch) |
| [`open77_ripperdoc_example`](open77_ripperdoc_example/) | A replaceable ripperdoc role-play example: a doctor offers to install, inspect or remove Gorilla Arms and double-jump legs on a nearby patient, the patient accepts by holding E, and the procedure is paid from a session-only clinic credit balance. | [Cyberware](https://open2077.net/docs/cyberware) |
| [`pursuit`](pursuit/) | Pursuit gives your server a cops-and-runners 1v1 in Night City: players queue in a lobby, get paired into a private match, and one plays the cop while the other tries to break away. | [Writing a gamemode](https://open2077.net/docs/writing-a-gamemode) |
| [`pursuit_hud`](pursuit_hud/) | Draws the Pursuit match HUD for each player: their role, the queue position, the countdown and round timer, the bust and escape meters, the score, and for the runner the live separation and scanner age. | none yet |
| [`race`](race/) | This is a compatibility alias: races now run inside [freeroam](../freeroam/), and this resource only exists so an older server profile that still loads `race` starts Freeroam instead. | none yet |

Exported from the Open77 platform repository; `EXPORT.json` names the commit.
