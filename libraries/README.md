# libraries

Shared code other resources depend on: PolyZone zones and the ArchiveXL / TweakXL loaders.

| Resource | What it does | Docs |
|---|---|---|
| [`polyzone`](polyzone/) | Gives your Lua resources polygon, box, circle and sphere, moving entity and combined zones, with enter and exit callbacks and an in-game zone editor. | [PolyZone](https://open2077.net/docs/polyzone) |
| [`archivexl`](archivexl/) | Installs the ArchiveXL loader in your players' games, so your world resources can use `.xl` extensions: streaming blocks, sector patches, resource patches and dynamic appearances. | [Mods your server requires](https://open2077.net/docs/server-mods), [Mods: the complete guide](https://open2077.net/docs/mods) |
| [`tweakxl`](tweakxl/) | Installs the TweakXL loader in your players' games, so your world resources can add TweakDB records from `r6/tweaks` YAML files, such as fast travel points, vehicles and items. | [Mods your server requires](https://open2077.net/docs/server-mods), [Mods: the complete guide](https://open2077.net/docs/mods) |

Exported from the Open77 platform repository; `EXPORT.json` names the commit.
