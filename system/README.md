# system

The platform resources every Open77 server runs on: chat, HUD, vehicles, weapons, NPCs, prompts, doors, animations and more. Your server download already contains this folder; copy a resource from here only to update it.

| Resource | What it does | Docs |
|---|---|---|
| [`open-voice`](open-voice/) | Gives players three voice ranges (whisper, normal and shout) that they cycle with F11, and a small HUD line that shows the active range and whether they are talking. | [Integrated voice chat](https://open2077.net/docs/voice) |
| [`open77_actions`](open77_actions/) | Runs the part every job action repeats: a prompt on a spot, a timed animation with a progress bar, server checks, one player per spot, and carrying crates into vehicles. | [Actions and carrying](https://open2077.net/docs/actions), [Build a job: prompts, animations, items and pay](https://open2077.net/docs/world-interaction) |
| [`open77_admin`](open77_admin/) | Gives server operators an in-game admin menu (`/admin`) and a full admin console (`/adminfull`) to manage players, vehicles, weapons, props, doors and the weather, with every action checked against the server's ACL. | [Public identity, server commands, and ACL](https://open2077.net/docs/server-acl) |
| [`open77_animations`](open77_animations/) | Plays synchronised role-play animations on players: more than a hundred poses, gestures, dances, workspots and walking actions that every nearby player sees, started with the `/anim` command or from your own resource. | [Role-play animations](https://open2077.net/docs/rp-animations), [RP animation catalogue](https://open2077.net/docs/rp-animation-catalogue) |
| [`open77_appearance`](open77_appearance/) | Lets players create and change their character's look in the game's own character editor, and saves it on the server so it comes back every time they join. | [The join-time readiness gate](https://open2077.net/docs/readiness-gate), [Configure a SQL database](https://open2077.net/docs/database) |
| [`open77_avcleanup`](open77_avcleanup/) | Removes abandoned AVs (the flying vehicles) from the world, so empty Manticores and other AVs left behind by players do not pile up on your server. | [Network vehicles](https://open2077.net/docs/vehicles) |
| [`open77_blips`](open77_blips/) | Is the transparent, click-through overlay the platform uses to draw the custom icons other resources give their blips. | [Custom SVG blips](https://open2077.net/docs/custom-blip-icons), [Vanilla blips and mappins](https://open2077.net/docs/blips) |
| [`open77_chat`](open77_chat/) | Is the in-game chat: players press T to talk and run slash commands with completion, and other resources post messages and register command suggestions through it. | [Chat, slash commands, and completion](https://open2077.net/docs/chat) |
| [`open77_containers`](open77_containers/) | Gives a server durable world containers: crates, ground piles and depletable search nodes whose contents survive a restart, each shown as a server prop with an optional interaction prompt. | [Server-owned world props](https://open2077.net/docs/props), [Durable transactions](https://open2077.net/docs/transactions) |
| [`open77_contextmenu`](open77_contextmenu/) | Gives players an ALT + click context menu on players, vehicles, NPCs, doors, props and the world around them, filled only with the actions your own resources register. | [Generic context menu — open77_contextmenu](https://open2077.net/docs/context-menu), [Screen picking and cursor utilities](https://open2077.net/docs/screen-picking) |
| [`open77_cyberware`](open77_cyberware/) | Puts server-owned cyberware on players' bodies: it equips the implants the server says a player has installed (Gorilla Arms and double-jump legs), shows charged punches and their impacts to everyone around, and runs the Ground Slam ability. | [Cyberware](https://open2077.net/docs/cyberware), [Ground Slam / Quake](https://open2077.net/docs/ground-slam) |
| [`open77_dash`](open77_dash/) | Gives players the native ground dash and Air Dash once your server grants it to them: the player presses a key and the body dashes on that frame, in the direction they are moving or looking. | [Native Dash and Air Dash](https://open2077.net/docs/dash), [Ability activation leases](https://open2077.net/docs/ability-activation-leases) |
| [`open77_death`](open77_death/) | Gives client resources a read-only view of which players are alive or dead, and repeats every life-state change as one local event. | [Official resource exports](https://open2077.net/docs/resource-exports) |
| [`open77_debug`](open77_debug/) | Is the privileged developer toolkit for admins: it runs Lua on one player's client from a chat command, shows or hides vanilla HUD parts, and draws an aim inspector that names the object you look at. | [Privileged in-game Lua laboratory](https://open2077.net/docs/debug-runtime), [Vanilla HUD visibility](https://open2077.net/docs/hud-visibility) |
| [`open77_devices`](open77_devices/) | Turns a vanilla device prompt off on every client, such as the one on a vending machine, so your resource can put its own prompt there. | [Overriding a vanilla device prompt](https://open2077.net/docs/device-interactions) |
| [`open77_doors`](open77_doors/) | Makes the world's doors networked: the server decides whether each door is open, locked or sealed, and every player in the same routing bucket sees the same door move with its native animation. | [Networked world doors](https://open2077.net/docs/doors) |
| [`open77_effects`](open77_effects/) | Shows the server's visual and sound effects (fire, smoke, sparks, explosions and more) to every player nearby, and gives admins chat commands to fire one-shot or looping effects in the world. | [Visual and audio effects](https://open2077.net/docs/effects), [Props and effects](https://open2077.net/docs/props-and-effects) |
| [`open77_elevators`](open77_elevators/) | Makes the game's lifts networked: the server owns each elevator's floor, movement and schedule, and every player in the same routing bucket rides the same cabin. | [Network elevators](https://open2077.net/docs/elevators) |
| [`open77_forcedoor`](open77_forcedoor/) | Adds two chat commands that open the door the player is looking at, even when it is locked. | [Networked world doors](https://open2077.net/docs/doors) |
| [`open77_fuel`](open77_fuel/) | Gives every network vehicle a fuel tank: the server burns fuel from the car's speed and engine state once a second, cuts the engine when the tank is empty, and keeps it off until someone refuels. | [Replicated state bags](https://open2077.net/docs/state-bags) |
| [`open77_furniture`](open77_furniture/) | Is a read-only catalogue of the world's furniture spots: about 38,000 chairs, stools, benches, beds, counters, walls and rails across Night City, each with the sit, lean or lie poses an animation can be played at. | [Furniture: sit and lean](https://open2077.net/docs/furniture) |
| [`open77_groundcircle`](open77_groundcircle/) | Draws coloured circles on the ground for the local player, such as a ready-up ring or a job spot, without depending on any game asset to render. | [Drawing in the world](https://open2077.net/docs/world-drawing), [Official resource exports](https://open2077.net/docs/resource-exports) |
| [`open77_hacking`](open77_hacking/) | Is the player side of server-owned hacking: a player aims at another player and holds a key to upload a quickhack, and both players see, hear and feel the result. | [Hacking and counterplay](https://open2077.net/docs/hacking) |
| [`open77_helditems`](open77_helditems/) | Is the client half of the server's held-items service: it puts a real game item in the player's hand or another equipment slot when the server asks, takes it away again, and reports the result. | [Server-owned world props](https://open2077.net/docs/props) |
| [`open77_interactions`](open77_interactions/) | Shared interaction prompts for every Open77 resource: a small marker in the world that expands into a custom action card, with up to four choices, when the player is close enough and looking at it. | [Contextual world interactions](https://open2077.net/docs/interactions), [Build a job: prompts, animations, items and pay](https://open2077.net/docs/world-interaction) |
| [`open77_loot`](open77_loot/) | Puts server-owned item drops on the ground: the server creates each drop, every client shows it as a real object, and a pickup only counts once the server accepts it. | [Server loot and ground drops](https://open2077.net/docs/loot) |
| [`open77_markers`](open77_markers/) | Lets any client resource place 3D markers in the world (rings, cylinders, arrows and other shapes) through exports, without asking for the marker permission itself. | [3D world markers](https://open2077.net/docs/markers) |
| [`open77_media`](open77_media/) | Puts working televisions and screens in the world: an operator places a TV, monitor or panel prop and it shows a web page that every nearby player sees on its screen, with volume, mute, pause and a curtain. | none yet |
| [`open77_nameplates`](open77_nameplates/) | Draws a name above every other player within 35 m, and switches to squad-only plates in competitive modes so a name cannot be used to spot enemies through walls. | [Drawing in the world](https://open2077.net/docs/world-drawing) |
| [`open77_notifications`](open77_notifications/) | Shows toast notifications on screen: short messages, with an optional progress bar, that any resource can pop up for one player or for everyone. | [WebUI notifications](https://open2077.net/docs/notifications) |
| [`open77_npcs`](open77_npcs/) | Adds `npc.*` commands that spawn, move and control server-owned NPCs from the developer console or chat, and it is the reference code for Open77's NPC system. | [Server-owned NPCs](https://open2077.net/docs/npcs) |
| [`open77_pause`](open77_pause/) | Is the Escape menu players see on an Open77 server: it opens without pausing the world and offers Resume, City Map, Settings, Quit Session and Quit Game. | [Pause menu customization](https://open2077.net/docs/pause-menu) |
| [`open77_pedestrians`](open77_pedestrians/) | Brings Night City's sidewalks to life with server-owned NPCs: people sitting, leaning, praying or working at the game's own spots near each player, plus a walking crowd, all seen the same way by every player. | [Server-owned NPCs](https://open2077.net/docs/npcs) |
| [`open77_perspective`](open77_perspective/) | Lets players switch between first and third person with a key (F6 by default) and remembers their choice on each server, while the server decides whether third person is allowed at all. | [Third person](https://open2077.net/docs/perspective) |
| [`open77_player_interactions`](open77_player_interactions/) | Presents two-player interactions (giving an item, healing, carrying, escorting): the invited player gets an accept or decline prompt, and both players play matching animations in step once the server starts it. | [Player interactions](https://open2077.net/docs/player-interactions) |
| [`open77_playerstate`](open77_playerstate/) | Remembers where a player was and what condition they were in, and puts them back there when they return. | [The join-time readiness gate](https://open2077.net/docs/readiness-gate), [Configure a SQL database](https://open2077.net/docs/database) |
| [`open77_prediction`](open77_prediction/) | Is the operator control panel for prediction: it lets a server switch each prediction family on or off, set the ping ceiling, let a gamemode narrow the policy, and read how often predictions are refused. | [Prediction](https://open2077.net/docs/prediction) |
| [`open77_prevention`](open77_prevention/) | Applies the server's police policy (wanted level, the highest level allowed, and whether NCPD is dispatched at all) to each player's own game. | [Complete server Lua API](https://open2077.net/docs/server-api) |
| [`open77_props`](open77_props/) | Shows the server's world props and lights to every player near them, and gives admins chat commands to place, move, carry and remove props. | [Server-owned world props](https://open2077.net/docs/props), [Props and effects](https://open2077.net/docs/props-and-effects) |
| [`open77_reflex`](open77_reflex/) | Runs reflex overdrive, a boost your server grants: the player presses a key and their own body moves and attacks faster for a few seconds, while the world and every other player keep normal speed. | [Reflex overdrive](https://open2077.net/docs/reflex-overdrive), [Ability activation leases](https://open2077.net/docs/ability-activation-leases) |
| [`open77_remote_camera`](open77_remote_camera/) | Gives a server remote cameras and live video screens: a camera placed in the world renders its own view, which players watch on a screen in the world, in a rectangle of their HUD, or behind a web page. | [Remote cameras and world screens](https://open2077.net/docs/remote-camera) |
| [`open77_reticle`](open77_reticle/) | Draws an aiming reticle (a dot with four ticks) in the middle of the screen when a player aims a weapon in the Open77 third-person view (F7). | [Third person](https://open2077.net/docs/perspective) |
| [`open77_rp_basics`](open77_rp_basics/) | Gives a server three player-to-player role-play verbs, cuff, escort and search, published as server exports and wrapped in the bookkeeping that keeps a held player recoverable. | [The role-play kit](https://open2077.net/docs/rp-kit) |
| [`open77_seating`](open77_seating/) | Lets players sit, lean and lie down on the world's real chairs, stools, benches, counters, walls and beds, with a prompt on E or the `/sit` command, and keeps one player per seat. | [Furniture: sit and lean](https://open2077.net/docs/furniture) |
| [`open77_shell`](open77_shell/) | Is the connection screen players see while they join a server: it shows the connection, download and loading progress, lets the player cancel, and offers Retry connection, Return to launcher and Quit game when something goes wrong. | [The OPEN//77 launcher](https://open2077.net/docs/launcher), [Custom loading screens](https://open2077.net/docs/loading-screens) |
| [`open77_sound`](open77_sound/) | The bundled audio service: plays **an audio file a resource ships**, in 2D or in the world, with volume, looping, pitch and distance falloff. | [Resource audio](https://open2077.net/docs/sound) |
| [`open77_traffic`](open77_traffic/) | Fills the roads around every player with server-owned ambient cars and NPC drivers, driven by the game's own traffic system, and gives operators a panel to tune, pause and reset the fleet. | [Networked vehicle AI](https://open2077.net/docs/vehicle-ai) |
| [`open77_transactions`](open77_transactions/) | Is the server's durable ledger for items and money: paying for a job, giving items, selling between players or stocking a stall all happen as one operation that is applied exactly once and leaves a receipt. | [Durable transactions](https://open2077.net/docs/transactions) |
| [`open77_uikit`](open77_uikit/) | Draws the on-screen dialogs most gamemodes need: progress bars, text hints, alerts, input forms, context and keyboard menus and a radial wheel. | [The UI kit](https://open2077.net/docs/ui-kit) |
| [`open77_vehiclepicker`](open77_vehiclepicker/) | Gives any gamemode a vehicle picker panel that players use before a match: one curated roster per list, and one remembered choice per player. | [Network vehicles](https://open2077.net/docs/vehicles) |
| [`open77_vehicles`](open77_vehicles/) | Adds `vehicle.*` commands that spawn, lock, paint, damage, repair and seat players in server-owned network vehicles, plus client exports to read them. | [Network vehicles](https://open2077.net/docs/vehicles) |
| [`open77_voice`](open77_voice/) | Turns on in-game voice chat: players talk with push-to-talk (N by default) to everyone nearby, and to the radio, phone and party channels the server lets them speak on. | [Integrated voice chat](https://open2077.net/docs/voice), [Voice lipsync](https://open2077.net/docs/voice-lipsync) |
| [`open77_wardrobe_ui`](open77_wardrobe_ui/) | Is the in-game wardrobe: a fitting room where players preview and save worn clothing, star favorite items, and build up to seven named outfits that other players see once saved. | none yet |
| [`open77_watermark`](open77_watermark/) | A small, passive watermark centred at the top of the HUD that shows the OPEN//77 logo, the **Open Stress Test** event label, and a quiet line with the player's name and ID, the client build and a shortened session identifier. | [Vanilla HUD visibility](https://open2077.net/docs/hud-visibility) |
| [`open77_weapons`](open77_weapons/) | Gives, removes and reloads the weapons in a player's three weapon slots, and makes explosions push nearby cars and knock down NPCs (and players, when your gamemode allows it) on every screen. | [Weapon Lua API](https://open2077.net/docs/weapons-api), [Weapon customization](https://open2077.net/docs/weapon-customization) |
| [`open77_weather`](open77_weather/) | Keeps the server clock and weather in sync, so players see the same time of day and the same sky, and it gives operators `weather.*` commands to change them. | [Synchronised time and weather](https://open2077.net/docs/weather) |
| [`open77_worldui`](open77_worldui/) | Puts a point of interest in the world with one call: a ground marker and an action prompt above it, created together under one handle and removed together. | [World-anchored POIs](https://open2077.net/docs/worldui) |
| [`open77_zones`](open77_zones/) | The client-side zone poller: enter/exit events with hysteresis, for spheres, boxes, polygons, combinations and entity-attached shapes. | [Zones](https://open2077.net/docs/zones) |

Exported from the Open77 platform repository; `EXPORT.json` names the commit.
