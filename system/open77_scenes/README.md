# open77_scenes

Synchronized RP scenes on the world's furniture. The first scene lies a player down on a ripperdoc's
surgical chair: sit down, two seated poses, get up — seen the same by every player of the bucket,
late joiners included. The playback is the platform's RP animation service
(`Open77.animations.sequenceAt`); this resource finds the spots, offers the prompts, keeps one player
per spot and walks the phases.

- Author guide: [`wiki/scenes.md`](../../../wiki/scenes.md)
- Research and live evidence: [`docs/research/rp-scenes.md`](../../../docs/research/rp-scenes.md)
- Spot catalogue: `server/spots-generated.lua`, regenerated by `scripts/scenes/` (do not edit)

Shipped in the server package (Freeroam template), opt-in (`auto_start false`): `resources.load`
admits `open77_animations`, `open77_interactions` and `open77_scenes`, then `ensure open77_scenes`.
Clients need `Open77Scenes.archive` (built and packaged with `Open77.archive`). Convars: `open77_scenes_reach` (3.0 m), `open77_scenes_prompt_radius` (3.0 m).

Tests: `server/tests/Open77.Server.Tests/Resources/ScenesLuaTests.cs` runs `tests/scenes_test.lua`
against `tests/fakes.lua` (the real shared and server halves).
