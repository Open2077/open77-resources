# tools

Build tools for content packs. Each folder mirrors the Open77 platform repository, so its scripts run unchanged: run them from the tool's folder.

| Tool | What it does | Docs |
|---|---|---|
| [`vehicle-kit`](vehicle-kit/) | The pipeline that builds Open77 vehicle customization packs: original rims, body kit parts, liveries, stickers, performance stages with engine sounds, plates and window tint, each as a resource ready to copy into a server, with its `preload_mod` ZIP. | [Vehicle customization content packs](https://open2077.net/docs/vehicle-customization-packs) |

Exported from the Open77 platform repository; `EXPORT.json` names the commit.
